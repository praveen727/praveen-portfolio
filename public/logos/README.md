Power BI and SQL have no logo file here: no licensed Power BI mark was available offline, so those two tiles use the
thin line icons in `src/components/ui/TechLogo.tsx` (CONCEPT map). To use the official Power BI logo instead,
drop `powerbi.svg` into this folder and add `powerbi` to the BRAND map in TechLogo.tsx.
